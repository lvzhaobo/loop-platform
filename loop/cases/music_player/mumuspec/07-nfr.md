# 非功能需求（NFR）

## 1. 性能

| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| 播放启动延迟 | 从点击播放到声音输出 < 100ms | 前端记录事件时间与音频首帧输出时间差 |
| API 响应时间（播放控制） | `POST /api/playback/play/pause/next/previous` < 100ms (P95) | 服务端日志或 APM |
| Seek 操作延迟 | `POST /api/playback/seek` 响应时间 < 50ms；实际音频位置误差 < 200ms | 客户端校验 |
| UI 帧率（拖拽进度条） | ≥ 55 fps | 浏览器 Performance API |
| 播放列表扫描性能 | 1000 个文件扫描时间 < 3s | 模拟测试 |
| 连续负载 | 连续 100 次随机操作无性能劣化 | 自动化测试 |

## 2. 可用性

| 指标 | 目标值 |
|------|--------|
| 连续运行稳定性 | 运行 2 小时无崩溃、无内存泄漏 |
| 后台播放韧性 | 应用进入后台时音频正常播放，API 可访问，无超时 |
| 健康检查 | `GET /api/health` 持续返回 200，响应时间 < 50ms |
| 错误恢复 | 播放损坏文件后自动切换下一首，系统无需人工干预 |

## 3. 安全

| 指标 | 要求 |
|------|------|
| 文件访问控制 | 仅允许访问配置的音乐目录及子目录，禁止路径遍历（如 `../`） |
| 参数校验 | 所有 API 输入进行严格校验（类型、范围、长度） |
| 错误信息泄露 | 生产环境不暴露堆栈或系统路径，仅返回标准错误码与用户可读消息 |
| 资源限制 | 限制单次扫描文件数量（如 <=5000），防止资源耗尽 |
| 依赖安全 | Flask 依赖项无已知高危漏洞（定期检查） |

## 4. 可维护性

| 方面 | 目标 |
|------|------|
| 配置管理 | 音乐目录路径、支持格式等可通过配置文件修改 |
| 日志 | 记录关键操作（播放、切换、错误），便于问题排查 |
| 数据存储 | JSON 文件结构清晰，支持手动编辑或迁移 |
