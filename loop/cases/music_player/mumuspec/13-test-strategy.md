# 音乐播放器 v1.0 测试策略

## 1. 测试范围
所有 6 个用户故事的 33 项验收标准（AC-001 ~ AC-033），包括功能测试、性能测试、兼容性测试、稳定性测试。

## 2. 测试分层
- **API 层测试**：自动化验证 API 输入输出，状态码，错误码，响应时间。
- **UI 交互测试**：自动化（浏览器/Electron 环境）验证前端状态、图标切换、布局等关键行为；人工抽检视觉感受、声音质量。
- **性能测试**：自动化监测帧率、响应延迟、内存和线程稳定性。
- **边界/异常测试**：自动化注入错误条件，验证错误提示与恢复。

## 3. 自动判定 vs 人工抽检
以下准则区分测试用例类型：
- **自动判定**：可通过脚本执行并按预期断言的功能点，包括 API 返回码/内容、UI 元素可见性/文本、响应时间指标、错误提示文案。
- **人工抽检**：主观听觉体验（如“无杂音”）、整体视觉舒适度（如暗色主题一致性）、极低概率交互流畅度（需人工评判）。

## 5. 测试环境
- 操作系统：Windows 11, macOS Ventura, Ubuntu 22.04
- 浏览器（如需）：Chrome 最新版（用于 Electron 前端）
- 工具：Postman/Newman（API），Cypress（UI），Lighthouse/axe-core（可访问性），性能监控脚本
