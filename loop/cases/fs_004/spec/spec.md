# 需求规格:图书管理后台

## 一句话概述
一个单页交互式图书管理后台，支持对图书进行增删改查操作。

## 核心交互
用户可以在一个页面上完成以下操作:
- 添加新图书(输入书名、作者等信息)
- 查看图书列表
- 编辑已有图书信息
- 删除图书

## 结构建议
- 前端:单页应用,所有交互在 `templates/index.html` 中通过 JavaScript 实现。
- 后端:Flask 应用,`app.py` 渲染首页并提供 JSON API 接口(如 `/api/books` 用于 CRUD)。
- 纯逻辑抽离:将图书数据的增删改查逻辑抽离为独立 Python 模块 `books_core.py`,该模块为纯函数,无副作用,便于单元测试。
- 测试:单元测试文件 `tests/test_books_core.py` 测试 `books_core.py` 中的函数。

## 非目标
- 不是内容列表站,没有列表页/详情页/数据集/图鉴。
- 不涉及用户认证、权限管理。
- 不涉及分页、搜索、排序等高级功能。
