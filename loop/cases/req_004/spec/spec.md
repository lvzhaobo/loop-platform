# 需求规格:招聘职位列表页

## 一句话概述
一个招聘职位列表页,用于展示当前开放的职位信息。

## 核心交互
用户能浏览招聘职位列表,查看每个职位的标题、部门、地点等基本信息。

## 结构建议
- 前端:单页 HTML,通过 JavaScript 从后端 API 获取职位数据并渲染列表。
- 后端:Flask 提供 `/` 渲染首页,以及 `/api/jobs` JSON 接口返回职位数据。
- 纯逻辑模块: `jobs_core.py` 包含职位数据的获取、过滤、排序等纯函数,无副作用,便于单测。
- 测试: `tests/test_jobs_core.py` 测试 `jobs_core.py` 中的核心逻辑。

## 非目标
- 不是内容列表站,没有详情页、数据集、图鉴。
- 没有职位申请、用户登录、搜索过滤等复杂交互。
- 没有分页、无限滚动等高级列表功能。
