## 验收条件 (Acceptance Criteria)

1. **US‑001 初始数组展示**  
   - AC‑001：调用 `GET /api/array?size=20` 返回 HTTP 200，响应体包含 `values` 字段，其值为长度 20 的整数数组，每个元素 > 0。  
   - AC‑002：前端根据 `values` 渲染条形图，所有条形使用默认颜色（蓝色 `#3498db`），无绿色或红色标识。

2. **US‑002 排序动画演示**  
   - AC‑003：调用 `POST /api/sort` 传入 `{ "algorithm": "bubble", "array": [5,3,8,1] }` 返回 HTTP 200，响应体包含 `steps` 数组，数组至少一个元素，每个步骤对象包含以下字段：  
     - `type` : `"compare"` | `"swap"` | `"complete"`  
     - `indices` : 整数数组，指明当前涉及的条形索引  
     - `colors` : 对象，如 `{ compare: "#e74c3c", swap: "#f39c12", sorted: "#2ecc71" }`  
   - AC‑004：前端按顺序消费 `steps`，发生比较时比较条形显示红色，发生交换时交换条形显示橙色并更新位置，步骤完成后该索引条形变为绿色，最终所有条形均为绿色。

3. **US‑003 暂停与继续**  
   - AC‑005：调用 `POST /api/sort/control` 传入 `{ "command": "pause" }` 返回 HTTP 200，响应体 `{ "status": "paused" }`，前端停止动画播放。  
   - AC‑006：调用 `POST /api/sort/control` 传入 `{ "command": "resume" }` 返回 HTTP 200，响应体 `{ "status": "running" }`，前端从当前步骤继续播放动画。

4. **US‑004 重置功能**  
   - AC‑007：调用 `POST /api/sort/control` 传入 `{ "command": "reset" }` 返回 HTTP 200，并同时返回新的随机数组 `{ "status": "reset", "values": [新数组] }`，前端清除所有动画状态，渲染新数组的条形图，所有颜色恢复为默认蓝色。

5. **US‑005 标识展示**  
   - AC‑008：调用 `GET /api/meta` 返回 HTTP 200，响应体包含 `identifier` 字段，其值为 `"Loop-20260723"`，前端将该字符串显示在标题或固定位置，文字清晰、无遮挡。

*注：所有 AC 均可在 API 契约（09‑api‑spec.md）中找到对应的路由、状态码、响应字段及错误码。*
