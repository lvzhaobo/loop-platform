# 产品需求文档 – 排序算法可视化网页 (FS-002)

## 1. 文档信息

- **需求编号**：FS-002
- **版本**：1.0
- **关联文档**：需求采集文档 FS-002、立项提案

## 2. 功能范围

### 2.1 核心功能 (Must have)

- **排序动画演示**：
  - 支持通过按钮启动、暂停、重置排序动画。
  - 条形图高度代表数值大小，在排序过程中动态变化位置。
  - 使用差异颜色标识当前比较元素、交换元素和已完成排序部分。
- **指定标识展示**：
  - 页面需在显眼位置（如顶部标题或底部固定栏）展示文字“Loop-20260723”。
- **主题与布局**：
  - 整体背景使用浅色（如 #f5f5f5 或纯白）。
  - 可视化区域居中，尺寸适配桌面和平板设备，不出现横向滚动条。
- **算法支持**：
  - 至少实现一种排序算法并完整动画化（推荐冒泡排序，因其比较与交换步骤清晰）。

### 2.2 可选增强 (Should/Optional)

- 提供算法选择器，可在多种排序算法间切换（如快速排序、插入排序等）。
- 提供速度调节滑块或元素数量调节滑块。
- 生成随机数据按钮，用于重新初始化数组。

> 本期仅交付核心功能，增强项可作为后续迭代方向。

## 3. 用户流程

1. **打开页面**
   - 用户用浏览器打开 HTML 文件。
   - 立即看到浅色背景、居中排列的条形图（代表待排序数组）、页面标题/水印含“Loop-20260723”。
   - 条形图初始状态为打乱顺序，所有条为默认颜色（如蓝色）。

2. **启动排序**
   - 用户点击“开始排序”按钮。
   - 动画启动：当前比较的条形变为红色；发生交换时，涉及的条形高亮（如橙色）并交换位置，然后恢复；已排好位置的条形逐渐变为绿色。
   - 整个过程持续自动进行，直至所有条形变绿。

3. **交互控制**
   - 排序过程中，用户可以点击“暂停”按钮，动画暂停，保留当前状态。
   - 再次点击“继续”或“开始排序”可恢复执行。
   - 任何时候点击“重置”按钮，所有条形回归初始随机顺序，颜色重置为默认色。

4. **结束状态**
   - 所有条形均为绿色，排序完成。按钮状态变更（如“开始排序”变为不可用或显示“已完成”）。

## 4. 验收条件

- **功能验收**
  - [ ] 页面显示“Loop-20260723”，文字清晰，未被遮挡。
  - [ ] 页面背景为浅色（视觉检查）。
  - [ ] 点击“开始排序”后，条形高度动态变化，最终数组按升序排列，且所有条形变为绿色。
  - [ ] 排序过程中出现至少两种高亮颜色（如红/橙），用于表示比较和交换。
  - [ ] 暂停/重置功能正常工作，状态保持或恢复初始随机数据。
  - [ ] 在 Chrome、Edge、Firefox、Safari 最新版本中运行，动画和布局无明显异常。

- **性能验收**
  - [ ] 使用浏览器 DevTools 的 FPS 计量器，动画稳定在 55-60 fps 之间。
  - [ ] 页面加载时间（从打开到可交互）< 2 秒。

- **代码与合规验收**
  - [ ] 整个应用为单个 HTML 文件，所有 CSS 和 JS 内联，无外部 CDN 依赖。
  - [ ] JS 代码包含注释，说明实现的排序算法、关键动画逻辑和可调节参数（如延迟毫秒数、元素数量）。
  - [ ] 页面具备基本响应式，在 1024px 宽度以上显示正常，无内容溢出。
