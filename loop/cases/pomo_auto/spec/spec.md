# 番茄钟 (pomo_auto)

## 一句话概述
一个单页番茄钟计时器，帮助用户按番茄工作法（25分钟专注 + 5分钟休息）管理时间。

## 核心交互
- 用户点击「开始」按钮启动一个25分钟的专注计时。
- 计时结束后自动进入5分钟休息计时，并循环。
- 用户可随时暂停/继续当前计时。
- 用户可重置计时器回到初始状态。
- 界面显示当前阶段（专注/休息）、剩余时间（分:秒）、以及已完成番茄数。

## 结构建议
- **前端**：`templates/index.html` 渲染页面，`static/js/pomo.js` 处理所有计时逻辑和UI更新。
- **后端**：`app.py` 仅渲染首页（`/`），无额外API接口。
- **纯逻辑模块**：`pomo_core.py` 封装计时核心逻辑（如时间计算、阶段切换、番茄计数），为纯函数、无副作用，便于单测。
- **样式**：`static/css/style.css` 提供基础样式。

## 非目标
- 不是内容列表站，没有列表页、详情页、数据集或图鉴功能。
- 不涉及用户登录、数据持久化或后端存储。
- 不包含音效或动画效果（仅基础UI反馈）。
