# 需求分析

## 一句话概述
番茄钟计时器：25分钟专注 + 5分钟休息循环。

## 核心功能点
1. 倒计时显示（mm:ss 格式）
2. 开始/暂停切换
3. 重置按钮
4. 专注/休息模式自动切换
5. 计时结束声音提示

## 技术约束
- 后端: Python Flask
- 前端: 原生 HTML/CSS/JS
- 存储: 无持久化（纯前端状态）

## 风险
- 低风险，功能明确，技术成熟
