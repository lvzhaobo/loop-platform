# DSH 企业培训 · 演示工程

同一份任务、同一个门禁，**三个装置**分别跑一遍。

```
demo/
├── config.env              ← 唯一配置点（key / 模型 / 工作区 / 策略）
├── shared/                 ← 装置无关的资产（换装置不用改）
│   ├── tasks.md            任务与验收条件
│   ├── check.py            门禁（7 条断言，退出码即判据）
│   ├── fixture/pomodoro/   起始工程（HTML+JS，门禁初始为红）
│   └── solution/           参考答案（讲师用）
├── A-python/               ← 装置一：自研 harness（~450 行）
├── B-dsh/                  ← 装置二：DSH + 沙箱
├── lab/                    ← 装置三的切片：30 分钟动手实验
└── docs/讲师手册.md
```

## 最直观的入口：演示控制台

```bash
./start.sh                 # 离线 mock，不需要 key
# 浏览器打开 http://127.0.0.1:8765
```

会起一个本地服务（零依赖，`http.server` + SSE），页面上：

| 区域 | 内容 |
|---|---|
| 顶部 | **两个内置任务**（番茄钟 / 智能客服）/ 自由任务 / 推送 / 停止 / 离线开关 / 自动批准 |
| 左·流程轨道 | 6 段，实时点亮：任务 → 读代码 → 工具 → 审批 → 门禁 → 完成 |
| 左·**命令白名单** | 5 条规则 + 每次尝试的命中结果（`rm -rf src` 显示"不在白名单"） |
| 左·**上下文水位** | 实时 token 估算、85% 阈值线、【模拟触发压缩】按钮 |
| 右·运行日志 | 逐步流式输出，拒绝红、通过绿、审批琥珀 |
| 右·**工作区代码** | 真实读沙箱文件，右侧显示 agent 改完的代码，改动文件带黄点 |
| 右·**上下文** | 逐条消息（system/user/assistant/tool）+ 压缩前后对比 |

**人工介入是真的会停**：agent 要写文件时弹出「需要你确认」，点通过才继续，点拒绝它会改方案。

### 两个任务，两种门禁强度

| 任务 | 被测代码 | 门禁怎么判 | 能验到什么 |
|---|---|---|---|
| 番茄时钟 | HTML + JS | **正则扫源码** | 只能验「写了什么」 |
| 智能客服 | Python | **直接 import 调用** | 能验「怎么表现」 |

这不是巧合，是这节课要讲的：**门禁的硬度取决于被测代码能不能被直接执行**。
所以 Python 后端项目的门禁，天然比纯前端项目的门禁更可信。

```bash
python3 reset.py        # 演示前复位：两个 fixture 都回到"门禁红"
```

## 不想跑代码？先看回放

双击 **`演示回放.html`** —— 点「开始演示」，逐行回放刚才那次真实运行，支持浅色/深色切换。

- `?auto=1` 自动播放　`?theme=dark` 强制深色
- 左侧点任意阶段可跳转，右侧终端会补上该阶段之前的全部输出

想看**两种装置并排对照**：双击 **`演示回放-v2.html`** —— 左边 IDE、右边 DSH，

## 30 秒跑起来

```bash
# 0) 配 key（或者不配，用离线 mock）
vi demo/config.env          # 填 DEEPSEEK_API_KEY

# 1) 先看门禁现状（应该是红的）
python3 demo/shared/check.py ; echo "退出码 $?"

# 2) 装置一：自研 harness（离线可跑，不烧钱）
cd demo/A-python
python3 main.py --mock --yes        # 演示：越权被拒 → 改文件 → 门禁绿
python3 main.py                     # 真实模型

# 3) 装置二：DSH
cd demo/B-dsh && ./run.sh

# 4) 装置三：动手实验
cd demo/lab && python3 lab_check.py  # 初始 4/7，做完 7/7
```

## 三个装置的区别只有一句话

| | 谁跑 loop | 能无人值守吗 | 能隔离吗 |
|---|---|---|---|
| IDE（CC / Qoder / Kiro / Cursor） | 产品 | ❌ | ❌ 跑在你的权限下 |
| A-python | 你自己写 | ✅ | 看你怎么写 |
| B-dsh | 框架 | ✅ | ✅ 沙箱 |

**`shared/` 里的东西三个装置都不改一个字** —— 这就是「工程可移植，装置可替换」。

## 三个必讲的瞬间

1. **`--check-safety` 报警**：把 harness 放进工作区，agent 就能改掉自己的白名单
2. **改 AGENTS.md 也拦不住 `rm`**：提示词是概率，白名单是确定性
3. **门禁红了不许合并**：agent 说"我做完了"不算数，退出码才算

## 依赖

只需要 Python 3.8+，**零第三方库**。真跑模型时需要一个 DeepSeek key（也可以 `MOCK=true` 完全离线）。
