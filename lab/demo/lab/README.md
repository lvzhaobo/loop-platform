## 验收是怎么判的（这段值得读）

`lab_check.py` 不检查你"写了没写"，而是检查**行为**：

- TODO 1：真的调 `allowed()` / `run()`，看放行与拒绝是否符合预期
- TODO 2：**把参考答案拷进 fixture，看你的门禁是否判绿；再还原，看是否判红**
  —— 只会判绿的断言是假门禁，只会判红的也是
- TODO 3：连续喂 5 次同一动作，看第几次升级；再喂 4 个不同动作，看有没有误判
