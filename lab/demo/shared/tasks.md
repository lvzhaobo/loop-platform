# 任务：给番茄时钟加上自定义时长

## 背景
`fixture/pomodoro/` 里是一个能用的番茄时钟：25 分钟工作 + 5 分钟休息，可以开始/暂停/重置。
但时长是写死的，产品同学希望能自己设。

## 要做的事
1. 页面上加两个数字输入框，让用户可以改「工作时长」和「休息时长」（单位：分钟）
2. 改完之后，下一次运行按新时长走（不需要刷新页面）
3. 输入非法值（0、负数、非数字、超过 180）时，回退到默认 25 / 5，并在界面上给一句提示

## 验收条件（必须精确到可判定 —— 门禁就是按这个写的）
- [ ] 存在 `<input id="work-minutes" type="number">` 和 `<input id="break-minutes" type="number">`
- [ ] `app.js` 从这两个控件读取数值（`getElementById('work-minutes')` 或 `querySelector('#work-minutes')`）
- [ ] 读取后按 `分钟 * 60` 换算成秒，赋给工作时长 / 休息时长
- [ ] 非法值（≤0 或 >180 或 NaN）回退到 25 / 5
- [ ] 原有功能不回归：开始 / 暂停 / 重置 / 自动切换 work↔break 仍然工作

## 不允许做的事
- 不允许修改 `check.py`（门禁是裁判，不是选手）
- 不允许删除或跳过任何一条断言
- 不允许引入任何第三方库（必须保持零依赖、双击 index.html 就能跑）

## 交付物
- 改好的 `index.html` / `app.js`
- `python check.py` 退出码为 0
