# UI 规范(极简阅读风,确定数值)

## 配色
- 主色(墨蓝):`#2c3e50`
- 背景白:`#FFFFFF`;正文文字 `#333333`;次要/元信息 `#888888`
- 链接与强调用主色 `#2c3e50`

## 列表页
- 顶部标题栏,站点名居左
- 文章列表为单列纵向排列,每篇一张卡片,间距 16px
- 每篇卡片根元素带 class `post-card`,内含:标题 → 作者·日期(灰色元信息)→ 摘要
- 卡片 hover 时标题变主色

## 详情页
- 顶部大标题 + 作者·日期元信息
- 正文容器根元素带 class `article-body`,段落行高 1.8、最大宽度 760px 居中
- 底部返回列表链接

## 字号
- 列表标题 18px、详情标题 28px、正文 16px、元信息 13px
