# UI 规范(淘宝风格,用确定数值,禁止"尽量像")

## 配色
- 主色(淘宝橙):`#FF5000`
- 价格红:`#FF0036`
- 背景灰:`#F5F5F5`
- 文字主色:`#333333`;次要文字:`#999999`

## 列表页 list.html
- 顶部搜索栏:高 48px,橙色搜索按钮
- 商品栅格:每行 4 列(≥1200px)/ 2 列(移动端),卡片间距 12px
- 卡片:白底、圆角 4px、hover 上浮阴影
- 卡片内:方形主图 → 标题(2 行截断)→ 价格(红色,¥ 符号小一号)→ 划线原价(灰)→ 月销量 → 店铺名

## 详情页 detail.html
- 左侧大图(≥ 400px 方形),右侧商品信息
- 价格区:红底或红字大号价格 + 划线原价 + 标签
- "加入购物车"(橙)+ "立即购买"(红)两个按钮(点击弹 alert 占位即可)
- 下方商品描述区

## 字号
- 标题 14px、价格 20px、次要信息 12px
