# 需求规格:番茄时钟(Pomodoro Timer)

## 一句话
一个单页番茄工作法计时器:默认 25:00 倒计时,可开始/暂停/重置,计时结束给出明显提示。

## 核心交互
- 页面打开即显示 `25:00`(分:秒),这是一个专注时段的默认时长。
- 「开始」按钮:点击后每秒递减一次,显示实时更新(浏览器端用 setInterval 驱动)。
- 「重置」按钮:随时把时间归回 25:00 并停止计时。
- 计时到 0:停止,并通过明显的视觉变化(如背景变红)提示时段结束。

## 结构建议
- 后端 `app.py` 只负责渲染首页 `/`(把默认时间渲染进模板),很薄。
- 倒计时的**纯逻辑**抽到 `timer_core.py`:
  - `format_time(seconds) -> "MM:SS"`,例如 `format_time(1500) == "25:00"`。
  - `tick(seconds) -> seconds-1`(不小于 0),例如 `tick(1500) == 1499`。
- 前端 `static/js/timer.js` 用 `setInterval` 每秒调用递减并刷新显示;复刻 `format_time` 的显示逻辑。
- `tests/test_timer.py` 针对 `timer_core` 断言:`format_time(1500)=="25:00"`、`format_time(tick(1500))=="24:59"`、到 0 不为负。

## 非目标
- 不是内容列表站;没有列表页/详情页/数据集/图片。
- 不需要账号、数据库、外部服务。
