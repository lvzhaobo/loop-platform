# UI 规范(淘宝风格,确定数值)

## 配色
- 主色(淘宝橙):`#FF5000`
- 价格红:`#FF0036`
- 背景灰:`#F5F5F5`;文字主色 `#333333`;次要 `#999999`

## 列表页
- 顶部搜索栏高 48px,橙色搜索按钮
- 商品栅格每行 4 列(桌面),卡片间距 12px;卡片白底、圆角 4px、hover 上浮
- 卡片:方图 → 标题(2 行截断)→ 红色价格 → 灰色划线原价 → 月销量 → 店铺
- 每个商品卡片根元素带 class `product-card`

## 详情页
- 左侧大图 ≥ 400px 方形,右侧信息
- 红色大号价格 + 划线原价 + 标签
- 两个按钮:`加入购物车`(橙 class `btn-cart`)+ `立即购买`(红 class `btn-buy`)
- 下方描述区

## 字号
- 标题 14px、价格 20px、次要 12px

## 结构标记(compile_spec 从此表派生 case.json 的 UI 字段)
| 键             | 值                |
|----------------|-------------------|
| list_marker    | product-card      |
| detail_markers | btn-cart, btn-buy |
| required_colors| #FF5000, #FF0036  |
