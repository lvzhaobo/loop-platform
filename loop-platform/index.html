Maker 配置

    
配置“谁来生成代码”的运行器（Maker）。生成端可插拔，验收端（Checker）不变——不管用哪个 Maker，产物统一过门禁。

  

  
支持的运行器类型

  

    
API 型
一发一收文本，平台落盘。对接 DeepSeek / OpenAI / Claude 等 Chat API，支持 temperature+seed 确定性。

    
CLI Agent 型
交出工作目录 + prompt，外部 agent 自己读写文件迭代。对接 claude-code / qoder-cli / copilot-cli / cursor-agent。

Maker / Checker

    
两大可复用部件：谁生成、谁验收。换任务只换 spec/facts/constraints，部件不动。

  

  

    
Maker·生成器
职责：拿上下文 → 拿产物 → 落盘。不做判断。对应 lib/model.py。
  • 输入：前馈约束 + Spec + facts
  • 输出：代码/文档产物
  • 模式：real（DeepSeek）/ sample（离线参考）

    
Checker·验收器
职责：产物 → 逐条 PASS/FAIL + 报告。对应 lib/gates.py。
  • 真起 Flask、真打路由、真跑单测
  • 判据来自 constraints/spec/facts
  • 输出：verify-report.json + summary.md

  

  
⚠ 边界：Harness 不是第三个文件，它 = Checker + 它所依赖的 constraints/spec/facts。Checker 是“执行检查的手”，判据来自约束与契约。
