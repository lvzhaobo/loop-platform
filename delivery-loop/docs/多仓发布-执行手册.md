## 2. 组装（本地，安全可逆）

一条命令把两个新仓组装到 `dist-repos/` 并做首次**本地提交**：

```bash
cd /Users/lvzhaobo/code/20260728/demo-2
bash delivery-loop/publish/build_repos.sh
```

脚本做了什么（`delivery-loop/publish/build_repos.sh`）：

1. 清空并重建 `dist-repos/loop-platform`、`dist-repos/loop-specs`。
2. **curated 拷贝**：把 `harness-4/`、`delivery-loop/` 拷进 platform，**排除**
   `__pycache__/`、`*.pyc`、`.venv/`、`output/`、`backlog/feishu_state.json`、
   `backlog/feishu_docs.json`、`backlog/backlog.jsonl`（运行时/私有态）。
3. 放入脚手架：`README.md`、`.gitignore`、`.env.example`、
   `backlog/feishu_docs.example.json`、`backlog/backlog.example.jsonl`。
4. specs 仓：拷 `cases/*/spec/*.md` + `checklist.md` + `README.md` + `.gitignore`。
5. 各仓 `git init && git add -A && git commit`（**本地提交，不推远端**）。

> 产物在 `dist-repos/`（已被本手册的忽略清单排除，不会污染发布内容）。删掉即可重来，完全可逆。

## 3. 密钥复检（发布前必过）

组装完，对 `dist-repos/` 再扫一遍，确认无真实密钥：

```bash
cd /Users/lvzhaobo/code/20260728/demo-2
grep -rInE '(sk-[A-Za-z0-9]{16,}|ghp_[A-Za-z0-9]{20,}|github_pat_|-----BEGIN|password[[:space:]]*=)' dist-repos --include='*.py' --include='*.js' --include='*.env*' --include='*.json' | grep -v example
# 期望：无输出（或仅 .example 占位）。有真实值 → 停，先清理再发布。
ls dist-repos/loop-platform/.env 2>/dev/null && echo "❌ .env 混入！" || echo "✅ 无 .env"
```

## 4. 远端建仓 + 推送（对外动作，确认后执行）

`gh` 未装，用 **GitHub API** 建私有仓（token 从 `.env` 读，需 **Contents: write + Administration: write** 权限来建仓）：

```bash
cd /Users/lvzhaobo/code/20260728/demo-2
bash delivery-loop/publish/push_repos.sh          # 交互确认后：建私有仓 + 加 remote + 推送
```

或**手动网页建仓**（更稳）：在 GitHub 新建 `loop-platform`（私有）、`loop-specs`（私有），再：

```bash
cd dist-repos/loop-platform
git remote add origin https://<TOKEN>@github.com/lvzhaobo/loop-platform.git
git -c http.version=HTTP/1.1 push -u origin main

cd ../loop-specs
git remote add origin https://<TOKEN>@github.com/lvzhaobo/loop-specs.git
git -c http.version=HTTP/1.1 push -u origin main
```

> `<TOKEN>` 用 `.env` 里的 `GITHUB_TOKEN`（**别写进任何文件/历史**，命令用完即弃）。

## 5. 回滚

- 组装产物：`rm -rf dist-repos/` 即可，源工作区不受影响。
- 远端误建：GitHub 网页 Settings → Delete repository。
- 本地提交想重来：删 `dist-repos/<repo>/.git` 后重跑 `build_repos.sh`。

## 6. 安全红线（再强调）

1. `.env` 永不进仓——脚本已排除，`.gitignore` 已列，复检兜底。
2. token 之前在对话中明文出现过 → **强烈建议 Regenerate**，新 token 最小权限。
3. `feishu_docs.json`（含你私有文档 token）**不发布**，只发 `.example` 占位版。
4. 平台/规格仓建**私有**；`loop-sample` 公开（Actions 免 token 拉取）。
